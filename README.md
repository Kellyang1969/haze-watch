# Haze Watch (Vite)
Singapore haze (NEA via data.gov.sg) and ASEAN weather/air quality (Open-Meteo).

    npm install
    npm run dev      # local dev server
    npm run build    # outputs dist/ (relative paths, GitHub Pages ready)

Deploy: push this folder to GitHub, then Settings > Pages and publish `dist/`
(or add a Pages workflow that runs `npm run build`).
